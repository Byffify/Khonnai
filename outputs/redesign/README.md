# ภาพร่าง Layout — รอตัดสินใจ

เปิด index.html เพื่อสลับภาพร่างมือถือ/Desktop และฟอนต์สองตัว ภาพร่างไม่ใช่แอปจริง ไม่บันทึกข้อมูลและไม่เชื่อม localStorage ของร้าน

## ข้อกำหนดที่คงเดิม

- สีและ tokens ตาม DESIGN.md: ขาว, #191919, #0968f6, รูป 16px, ปุ่ม 52px, ข้อความหลัก 18px
- สินค้า → ไซซ์ → สี/คละสี จำนวนขายได้ คงเหลือ จอง พร้อมหน่วย
- ฟอร์มและผลการบันทึกตาม PRODUCT.md / UX-CONTRACT.md ไม่มีการเปลี่ยนธุรกิจ
- ทุกการขายมีบิลและตัดทันที ไม่มีปิดวัน localStorage เหมือนเดิม
- ไม่เพิ่ม Dashboard กราฟ Chat แจ้งเตือน หรือเกณฑ์สต็อกต่ำ

## ข้อเสนอสำหรับเลือกก่อน implement

- การ์ดสินค้าบน surface เดิม พื้นการ์ดขาว ไม่มีเงาตกแต่ง
- เมนูล่างมือถือ / sidebar desktop พร้อมไอคอนและชื่อไทย ใช้ชุดไอคอนเส้นเดียวกัน
- Desktop แยกข้อมูลสินค้าและตัวเลือกเป็นสองคอลัมน์; บิลแยกรายการกับยอดรวม ข้อมูล/flow เท่าเดิม
- ฟอนต์ A IBM Plex Sans Thai Looped (แนะนำ) เทียบ B Prompt; ขนาด/น้ำหนักตาม tokens เดิม
- Desktop breakpoint เสนอ 1024px; tablet/mobile กลับคอลัมน์เดียวเพื่อคงพื้นที่แตะ
- รูปเป็น placeholder และรายการสมมติใช้เฉพาะภาพร่าง ไม่ใช่ข้อมูลของร้าน

ยังไม่แก้ DESIGN.md / UX-CONTRACT.md หรือ source ของแอป จนกว่าเลือกแบบและฟอนต์

## ฟอนต์อ้างอิง

- https://fonts.google.com/specimen/Prompt — Prompt
