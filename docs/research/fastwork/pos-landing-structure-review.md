# โครงเรื่อง Khonnai เทียบหน้า POS

ตรวจ18ตุลาคม2026. เป้าหมายคือแก้การเล่าซ้ำ ไม่เพิ่มฟีเจอร์หรือทำให้หน้ายาวเท่าบริษัทใหญ่.

## แหล่งที่อ่าน

- [Wongnai POS](https://www.wongnai.com/pos/) อ่านทั้งหน้าและ DOM ใน browser จริง. โครงมีคำสัญญาและหลักฐานแบรนด์, เลือกประเภทร้าน, ผลลัพธ์ของเครื่องมือ, อุปกรณ์, แพ็กเกจ, ติดต่อ/ความช่วยเหลือ.
- [FoodStory](https://www.foodstory.co/) ในวันที่ตรวจ redirect มาหน้า Wongnai POS จึงไม่นับเป็นอีกตัวอย่างอิสระ.
- [Loyverse ภาษาไทย](https://loyverse.com/th) อ่านโครงจาก official page. แยกความสามารถ, ประเภทธุรกิจ, เสียงผู้ใช้, ความช่วยเหลือ, FAQ และเส้นทางเริ่มใช้. ไม่ได้ทดลองระบบ POS หรือยืนยันทุกข้อความการตลาดของทั้งสองราย.

ข้อสังเกตจากแหล่งข้อมูลคือแต่ละส่วนช่วยตอบคำถามคนซื้อคนละข้อ. การมี feature หลายส่วนไม่ใช่ปัญหาเสมอไป หากแต่ละส่วนมีเหตุผลใหม่ให้ตัดสินใจ. Khonnai มีขอบเขตแคบกว่า จึงไม่ต้องคัดลอกจำนวน section.

## โครงใหม่และคำถามที่ต้องตอบ

1. **Hero และภาพร้านหลายมุม**. คนในคืออะไร ช่วยใคร และควรทำอะไรต่อ.
2. **งานที่รองรับแบบแถวสั้น**. ไปดูงานที่สนใจได้โดยไม่ต้องอ่านทุกอย่าง.
3. **เหมาะกับใคร**. เจ้าของดูแลข้อมูลเอง สินค้าหลายตัวเลือก อยากเริ่มทีละน้อย. ไม่ขยายเป็นร้านทุกประเภท.
4. **Demoเดียว**. เลือกสินค้า→ไซซ์/สี→ตรวจยอด→บิลและยอดใหม่. ให้เห็นกลไกพอเข้าใจ พร้อมตัวเลือกลองเองแบบย่อย.
5. **เตรียมอะไรและข้อมูลอยู่ไหน**. เบราว์เซอร์เครื่องหลัก ข้อมูลสินค้าชุดเล็ก และไฟล์สำรอง JSON. ไม่สร้าง cloud/hardware integration ที่ไม่มี.
6. **ราคาและเงื่อนไข**. แผนFree/Basic/Proในอนาคต สลับรอบราคาได้ พร้อมข้อจำกัดตามจริง.
7. **FAQและเริ่มใช้**. ตอบข้อกังวลก่อนลงมือ.

จุดที่ยังไม่มีหลักฐานคือรีวิวลูกค้า ผลลดเวลา ยอดร้านใช้งาน และทีมบริการจริง. ไม่เติมเรื่องเหล่านี้เพียงเพื่อให้ครบส่วนเหมือนเว็บใหญ่. เมื่อมีผลทดลองร้านจริง จึงค่อยเพิ่ม case study ที่เล่าปัญหา การใช้ และผลที่วัดได้.

## การปรับตามคำขอก่อนหน้าในรอบเดียวกัน

- เอาปุ่มหยุดแถบเลื่อนและปุ่มกลับไปดู Heroออกตามคำขอ. คงหยุดเมื่อ hover/focus/offscreen และ reduced motion.
- ราคาเป็นตัวเลขชุดเดิมเลื่อนออก ชุดใหม่เลื่อนเข้า พร้อม selector pill เคลื่อนระหว่างเดือน/ปี. ตัวเลขเป้าหมายและหน่วยชำระอัปเดตทันที ไม่ใช้เลขระหว่างทางเป็นราคาจริง.
- Heroใช้ภาพจำลองร้าน แพ็กสินค้า มือจัดสินค้า และภาพหน้าจอจากสไลด์ เข้าคนละทิศและจังหวะ. ไม่ใช่การ crop ภาพเดียวมาทำให้ดูเหมือนหลายภาพ.
