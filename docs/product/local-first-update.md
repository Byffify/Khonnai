# การเริ่มพัฒนารุ่น localStorage

วันที่ 14 ตุลาคม 2026 ผู้ใช้ขอ “เริ่มต้นทำแบบ localstorage ไว้หน่อย” แทนการเลือกระบบออนไลน์และล็อกอินในรอบนี้

- เริ่มเก็บสินค้า สต็อก จอง บิล และคืน/เปลี่ยนใน browser เครื่องเดียว
- ข้อกำหนดข้อมูลออนไลน์และย้ายมือถือโดยล็อกอินยังเป็นทิศทางภายหลัง ไม่ใช่ความสามารถของ localStorage
- งานที่พึ่งบริการออนไลน์ในแผนเดิมต้องปรับสำหรับรุ่นนี้ก่อนดำเนินการ และรายงานส่วนออนไลน์ว่าไม่ได้ทำ
- เสนอ Export/Import ข้อมูลเพื่อช่วยสำรองและย้ายข้อมูลด้วยมือ เป็นแนวทางประกอบรุ่น local ไม่ใช่การสำรองออนไลน์
- เมื่อเสนอว่าจะสร้างหน้าจอจากโค้ด ผู้ใช้เลือก “อยากดูภาพร่างก่อน” จึงต้องส่งภาพร่างก่อนเขียนหน้าจอ
- ยังไม่ได้เลือกข้อเสนอกติกากรณีบิลที่มีคืน/เปลี่ยนเชื่อมแล้วหรือยกเลิกบิลจากจอง ต้องแยกข้อเสนอจากข้อยืนยัน

## ภาพร่างสำหรับตรวจ

- ไฟล์: [local-mvp-mobile-v1.png](../../outputs/mockups/local-mvp-mobile-v1.png)
- แสดงหน้าสินค้าว่าง หน้าเพิ่มสินค้า และหน้าสร้างบิลว่าง ภาษาไทย ปุ่มใหญ่ เมนูสินค้า/บิล/จอง/คืนหรือเปลี่ยน
- เป็นภาพแนวทาง ยังไม่ใช่ระบบที่คลิกใช้งานได้ และยังไม่ได้เลือกเป็นแบบสุดท้าย
- รอความคิดเห็นผู้ใช้ก่อนพัฒนาหน้าจอตามคำขอให้ดูภาพร่างก่อน

## Design System และการพัฒนาต่อ

- ผู้ใช้กำหนดพื้นขาว ข้อความ #191919 สีหลัก #0968f6 และมุมรูปสินค้า 16px จากไฟล์อ้างอิง แล้วสั่ง implement ต่อโดยใช้ localStorage
- DESIGN.md เป็นข้อกำหนด visual หลัก ภาพร่างใหม่อยู่ที่ outputs/mockups/local-mvp-cobalt-v2.png และใช้เป็นภาพประกอบ ไม่ใช้ภาพ AI แทนหน้าจอจริง
- รุ่น local มีสินค้า/รูป/หน่วย/ไซซ์/สี/คละสี ราคา ยอดเริ่มต้น รับเข้า ปรับยอด บิล จอง คืน/เปลี่ยน PNG บิล และ JSON backup/import
- กติกาสำหรับป้องกันยอดซ้ำในรุ่นนี้: บิลที่มีคืน/เปลี่ยนเชื่อมล็อกจำนวนและยกเลิก แต่แก้ราคาได้; ยกเลิกบิลจากจองไม่ทำให้จองเดิมกลับมาเอง
