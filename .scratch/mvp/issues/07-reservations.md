# 07: จองสินค้าและยกเลิกจองจากมือถือ

**Status:** done

**Spec:** [MVP specification](../spec.md)

**Blocked by:** 04 — ขายผ่านบิลเงินสดและตัดสต็อกทันที

**What to build:** เจ้าของร้านกรอกจองจาก LINE แล้วจำนวนที่ยังขายได้ลดลง เปิดรายการค้างหรือยกเลิกจองได้

- [x] มีชื่อลูกค้า รายการ/ไซซ์/สี และจำนวน
- [x] จองไม่ตัดสต็อก แต่กันจำนวนที่ยังขายได้
- [x] ห้ามเกินจำนวนที่มี ใช้ข้อมูล localStorage ล่าสุดและตรวจ revision ก่อนบันทึก
