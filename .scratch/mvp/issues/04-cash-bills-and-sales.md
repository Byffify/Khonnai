# 04: ขายผ่านบิลเงินสดและตัดสต็อกทันที

**Status:** done

**Spec:** [MVP specification](../spec.md)

**Blocked by:** 02 — เก็บข้อมูลร้านใน localStorage และสร้างสินค้าพร้อมยอดเริ่มต้น

**What to build:** เลือกรหัส → ไซซ์ → สี/คละสี กรอกจำนวน ดูราคากับยอดรวม และบันทึกบิลพร้อมตัดสต็อก

- [x] ข้อมูลบนบิลครบตามสเปก ชื่อลูกค้าเว้นได้
- [x] ทุกการขายสร้างบิล ไม่มีการกรอกยอดรวมสิ้นวัน
- [x] ขายสำเร็จตัดทันที บิลและสต็อกสำเร็จร่วมกัน
- [x] ห้ามเกินจำนวนที่ยังขายได้ และจำนวนแพ็กต้องเต็ม
- [x] ราคาบนบิลเก่ายังเดิมเมื่อแก้ราคาสินค้า

- [x] เปิดประวัติบิลและข้อมูลหลังขายได้บนมือถือ
