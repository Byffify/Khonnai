# 02: เก็บข้อมูลร้านใน localStorage และสร้างสินค้าพร้อมยอดเริ่มต้น

**Status:** done

**Spec:** [MVP specification](../spec.md)

**Blocked by:** 01 — สรุปรุ่น localStorage และกติกาข้อมูล

**What to build:** เจ้าของร้านเข้าระบบ เพิ่มสินค้า/รูป/ไซซ์/สี/คละสี หน่วย ราคา และยอดเริ่มต้นจากมือถือ เปิดใหม่แล้วข้อมูลยังอยู่

- [x] ใช้ Vite + TypeScript + React + Tailwind เก็บข้อมูลใน localStorage ไม่มีล็อกอิน
- [x] เพิ่มและแก้ข้อมูลสินค้า รูปหลัก ตัวเลือกไซซ์/สี/คละสี หน่วย และราคา
- [x] เริ่มจากข้อมูลจริงหรือสถานะว่าง ไม่มีสินค้าจำลองในระบบร้าน
- [x] กรอกยอดเริ่มต้นจากกระดาษแล้วตรวจนับจริงได้
- [x] แพ็กคละมีไซซ์เดียวและยอดเดียว ไม่แยกสต็อกสีภายใน
- [x] เปิดใหม่ใน browser/profile/origin เดิมแล้วข้อมูลยังอยู่ พร้อม JSON export/import และตรวจข้อมูลเสียหาย; ออนไลน์/ล็อกอินย้ายไป future-online.md
- [x] ตรวจการใช้งานและการกรอกผ่าน browser viewport มือถือ; อุปกรณ์จริงรอนำร่อง
