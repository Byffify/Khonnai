# 10: เปลี่ยนสินค้าและบันทึกบิลสินค้าใหม่

**Status:** done

**Spec:** [MVP specification](../spec.md)

**Blocked by:** 09 — รับคืนทั้งมีและไม่มีบิลเดิม

**What to build:** รับของเดิม เลือกสินค้าใหม่ สร้างบิลของใหม่ตามกติกาทุกการขายมีบิล แล้วเพิ่ม/ลดสต็อกทันที

- [x] รองรับอ้างบิลเดิมและไม่มีบิลเดิมเช่นเดียวกับรับคืน
- [x] คืนของเดิมเพิ่มเฉพาะพร้อมขาย สินค้าใหม่ตัดทันทีและมีบิล
- [x] ตรวจสินค้าใหม่ไม่เกินจำนวนที่ยังขายได้ รวมยอดจองที่ใช้งานอยู่
- [x] การบันทึกส่วนรับคืนและขายของใหม่ต้องไม่ค้างครึ่งรายการเมื่อส่วนหนึ่งล้มเหลว
- [x] บิลและการคืนเชื่อมกับรายการเปลี่ยนโดยไม่บันทึกการเคลื่อนไหวซ้ำ
- [x] สินค้าแบบแพ็กใช้เต็มแพ็ก ไม่คำนวณเงินคืน/ส่วนต่าง
- [x] ตรวจเส้นทางเปลี่ยนและกติกาแก้/ยกเลิกที่ผูกกับรายการนี้
