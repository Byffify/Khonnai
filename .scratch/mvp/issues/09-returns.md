# 09: รับคืนทั้งมีและไม่มีบิลเดิม

**Status:** done

**Spec:** [MVP specification](../spec.md)

**Blocked by:** 06 — แก้บิลและยกเลิกบิลผิดพร้อมประวัติ

**What to build:** เลือกบิลหรือกรอกของคืนเอง เลือกพร้อมขาย/ขายต่อไม่ได้ แล้วเก็บรายการพร้อมยอดสต็อกถูกต้อง

- [x] ของพร้อมขายเพิ่มทันที ของขายต่อไม่ได้ไม่เพิ่มยอดพร้อมขาย
- [x] แบบแพ็กรับคืนเต็มแพ็ก
- [x] ถ้ามีบิล ตรวจยอดคืนสะสมไม่เกินที่ขายตามกติกาบิลล่าสุด
- [x] ไม่มีบิลให้เจ้าของกรอกเอง ไม่แสดงว่าได้ตรวจยอดซื้อเดิมแล้ว
- [x] รับคืนซ้ำจากคำขอเดียวไม่เพิ่มสต็อกซ้ำ
- [x] แก้/ยกเลิกบิลที่ผูกคืนไม่ทำสต็อกซ้ำตามกติกางาน 01
- [x] ไม่คำนวณเงินคืน
