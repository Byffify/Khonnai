# 03: รับสินค้าเข้าและปรับยอดตามการตรวจนับ

**Status:** done

**Spec:** [MVP specification](../spec.md)

**Blocked by:** 02 — เก็บข้อมูลร้านใน localStorage และสร้างสินค้าพร้อมยอดเริ่มต้น

**What to build:** เจ้าของร้านเลือกสินค้า รับเข้าเพิ่มทันที หรือแก้ยอดตามของจริง แล้วเปิดใหม่พบยอดที่บันทึก

- [x] รับเข้าตามหน่วยสินค้าพร้อมเพิ่มสต็อกทันที
- [x] ปรับยอดจริงได้โดยไม่บังคับเหตุผล ใช้กติกาประวัติตามงาน 01
- [x] สต็อกจริงไม่เป็นจำนวนติดลบ และแพ็กใช้จำนวนแพ็กเต็ม
- [x] บันทึกซ้ำจากคำขอเดิมไม่เพิ่มยอดซ้ำ
- [x] บันทึกล้มเหลวไม่แสดงสำเร็จ และข้อมูลที่กรอกยังแก้/ลองใหม่ได้
- [x] ตรวจการคงอยู่ของยอด localStorage และความถูกต้องจากหน้าใช้งาน
