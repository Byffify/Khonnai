# 01: สรุปรุ่น localStorage และกติกาข้อมูล

**Status:** done

**Spec:** [MVP specification](../spec.md)

**Blocked by:** None

**What to build:** ข้อตกลงรุ่น localStorage ตามคำสั่งผู้ใช้ พร้อมแยกออนไลน์/ล็อกอินเป็นงานภายหลัง

- [x] ใช้ localStorage ไม่มีล็อกอิน รูปย่อเก็บในข้อมูล local พร้อม JSON backup/import และข้อจำกัด origin/quota
- [x] กำหนดการแก้/ยกเลิกบิลที่มีคืน/เปลี่ยนเชื่อม และการยกเลิกบิลจากจอง
- [x] สรุปประวัติปรับยอด วิธีจัดการรูป และรูปแบบไฟล์บิล
- [x] เก็บชื่อหน่วยต่อสินค้าและจำนวนเต็ม ไม่แปลงหน่วยอัตโนมัติ; หน่วย/ยอดจริงให้ร้านกรอก
- [x] บันทึกข้อสรุปโดยแยกสิ่งที่ผู้ใช้เลือกจากแนวทางเทคนิค

**Note:** รุ่น local ได้รับอนุมัติแล้ว วิธีล็อกอิน/บริการออนไลน์ยังไม่ถูกเลือก ดู [งานภายหลัง](../future-online.md) กติกาบิลที่ผูกคืน/เปลี่ยนเป็นค่าเริ่มต้นทางเทคนิคใน implementation-plan.md
