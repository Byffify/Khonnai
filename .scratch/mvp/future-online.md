# งานภายหลัง — ข้อมูลออนไลน์และบัญชีเจ้าของร้าน

**Status:** needs-info

ผู้ใช้เลือกเริ่มด้วย localStorage ในรุ่นนี้ ข้อกำหนดต่อไปนี้พักไว้ ไม่ได้ถูก implement หรือทดสอบแล้ว:

- เลือกวิธีล็อกอินและการกู้บัญชี
- เลือกฐานข้อมูล/ระบบหลังบ้าน/ที่เก็บรูป และกำหนดสิทธิ์เข้าถึงข้อมูลร้าน
- เปลี่ยนการบันทึกหลายส่วนเป็น transaction ฝั่งระบบหลังบ้าน พร้อม idempotency และการตรวจฉบับข้อมูล
- ทดสอบเปิดข้อมูลจากมือถือเครื่องใหม่หลังเข้าสู่ระบบ
- กำหนดและทดลองการสำรอง/กู้ข้อมูลออนไลน์ ไม่ถือว่า local JSON export เป็น cloud backup
- ตัดสินใจวิธีย้ายข้อมูล local ปัจจุบันขึ้นระบบออนไลน์โดยไม่ซ้ำ

ข้อมูลสินค้าและยอดจริงต้องมาจากร้าน การตรวจอุปกรณ์มือถือจริง/คีย์บอร์ด/file picker และการทดสอบนำร่องกับเจ้าของร้านยังต้องทำก่อนสรุปผลใช้งานจริง
